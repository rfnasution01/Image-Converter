# Vite React TypeScript Tailwind Boilerplate

Boilerplate dengan alias `@`, shadcn/ui + Radix UI, React Hook Form, TanStack Query/Table, Axios, Tiptap, Chart.js, Font Awesome, dayjs, DOMPurify, Framer Motion, pdfmake, dan React Router.

## Mulai

```bash
npm install
npm run dev
```

## Script

- `npm run dev` menjalankan dev server.
- `npm run build` typecheck dan build production.
- `npm run lint` menjalankan ESLint.

## Struktur singkat

- `src/components/ui` komponen dasar ala shadcn/ui.
- `src/components/form` komponen form reusable.
- `src/lib` helper API, date, sanitize, pdf, className.
- `src/providers` provider aplikasi.
- `src/pages` halaman aplikasi.
